# Cursor project: Everything Films

Open this folder (or the `everything-films` GitHub repo) as its **own** Cursor project.

- Product name: **Everything Films**
- Business: wedding movies & life movies (send pictures/videos → finished film)
- Packages: 30 min / $10,000 · 60 min / $15,000
- Add-ons: rush, extra revision, dual cut, custom score, +15 min
- Outreach: wedding planners, funeral homes, wedding/birth/obituary announcements
- Partners: referral payouts $500 / $750
- **Not** Mobile Home Parks, not Project AIS, not Turner Biographies, not Turner Capital

## Roles

- Bradley: human ideas, priorities, approvals
- Agents: execute jobs inside Everything Films only

Name threads after the job, e.g. `Funeral partner wave 1`, `Obituary CSV import`, `Sample reel page`.

See root `OPS.md`.

## Do not continue this product inside VitalAI-PWA

VitalAI-PWA / Mobile Home Parks is a different business. New Cloud Agents for Everything Films must start from the `everything-films` project/environment.
