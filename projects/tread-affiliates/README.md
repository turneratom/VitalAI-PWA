# TREAD Marketing

Long-form traffic generation guide for **TREAD Marketing** — Skills → Vehicle → Monetisation.

## Run locally

```bash
cd tread-marketing
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Update CTAs

Edit `lib/links.ts` for:

- Glitchy signup URL
- Telegram invite
- YouTube resource links
- Swipe-file URL

## Stack

Next.js 16 · React 19 · Tailwind CSS 4 · Syne + Figtree
