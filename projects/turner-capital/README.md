# Turner Capital

Crypto & equities trading-floor simulation — twelve agents, two markets, one floor.

## Run locally

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080
# → http://localhost:8080
```

## Cursor project

This folder is the **Turner Capital** project. Open it (or its GitHub repo) as its own Cursor project — do not mix with Mobile Home Parks or Project AIS threads.
